# 任务清单

- [ ] #1 工程脚手架与 1920×1080 定屏基础（3 SP，优先级 high）
  - 说明：初始化 Vue 3 + TypeScript + Vite 工程，配置依赖与构建脚本，搭建 1920×1080 固定画布的等比缩放容器与全局禁滚动，提供空的 App 根组件挂载点。作为所有 UI 任务的前置依赖。
  - 依赖：无
  - 验收标准：npm install 与 npm run build 均成功；开发服务器启动后页面以 1920×1080 画布呈现并随窗口等比缩放、无滚动条；App 根组件可正常挂载渲染。

- [ ] #2 视觉基础层：毛玻璃卡片、风景背景与放松风格主题令牌（5 SP，优先级 high）
  - 说明：实现可复用的毛玻璃卡片组件 GlassCard（backdrop-filter 磨砂、圆角、半透明层次）、全屏大幅风景背景组件 BackgroundScene（支持背景源切换与交叉淡入淡出过渡），以及放松风格的主题令牌（配色、间距、圆角、模糊度、字体）。
  - 依赖：#1
  - 验收标准：GlassCard 呈现磨砂半透明+圆角效果并可包裹任意插槽内容；BackgroundScene 铺满 1920×1080 并支持切换背景且带平滑淡入淡出；主题令牌集中定义且被组件引用。

- [ ] #3 小憩会话状态与联动核心（Pinia Store）（3 SP，优先级 high）
  - 说明：建立 Pinia store 统一管理小憩会话状态：当前时段/背景选择、氛围参数、各功能卡片状态、小憩时长与运行/结束状态，并暴露 action 供卡片点击时驱动背景/氛围切换与时段风景切换。为联动集成提供数据契约。
  - 依赖：#1
  - 验收标准：store 提供背景/时段、氛围、时长、会话运行状态等字段与对应 mutation action；单元/手动验证下调用 action 能正确改变状态；类型定义完整通过 tsc。

- [ ] #4 功能卡片：座椅角度 / 按摩调节（3 SP，优先级 normal）
  - 说明：在毛玻璃卡片内实现座椅角度调节（滑动/档位）与按摩模式（开关+强度/模式选择），交互实时反馈可视化的座椅状态，状态写入 store。
  - 依赖：#2、#3
  - 验收标准：卡片可调节座椅角度并实时显示当前角度；可开关按摩并选择强度/模式；所有交互状态同步到 store 且界面即时反馈。

- [ ] #5 功能卡片：氛围灯与背景音乐 / 白噪音（5 SP，优先级 normal）
  - 说明：在毛玻璃卡片内实现氛围灯颜色/亮度调节与背景音乐/白噪音的选择、播放/暂停、音量控制，交互与 store 联动（氛围灯颜色可影响整体氛围）。
  - 依赖：#2、#3
  - 验收标准：可选择氛围灯颜色与亮度并即时预览；可选择并播放/暂停背景音乐或白噪音、调节音量；相关状态同步到 store。

- [ ] #6 功能卡片：香氛释放（2 SP，优先级 normal）
  - 说明：在毛玻璃卡片内实现香氛开关、香型选择与释放强度调节，交互实时反馈，状态写入 store。
  - 依赖：#2、#3
  - 验收标准：可开关香氛、选择香型并调节释放强度；界面即时反馈当前香型与强度；状态同步到 store。

- [ ] #7 功能卡片：遮阳帘 / 车窗调节（3 SP，优先级 normal）
  - 说明：在毛玻璃卡片内实现遮阳帘开合与车窗升降的连续/档位调节，交互带可视化开合度反馈，状态写入 store。
  - 依赖：#2、#3
  - 验收标准：可调节遮阳帘开合度与车窗升降度并实时可视化显示；状态同步到 store。

- [ ] #8 小憩时长设置（连续滑动）与结束唤醒流程（5 SP，优先级 high）
  - 说明：实现连续滑动的小憩时长自定义控件（实时显示分钟数），启动/取消小憩会话；会话倒计时结束时触发唤醒流程——背景灯光由暗渐亮并播放舒缓音乐，配合视觉提示唤醒用户。通过 store 编排会话生命周期。
  - 依赖：#2、#3
  - 验收标准：滑动可连续设置时长并实时显示；启动后会话进入倒计时、可取消；倒计时结束触发渐亮灯光+舒缓音乐的唤醒表现；会话状态经 store 编排。

- [ ] #9 主页面组装与组件联动集成（5 SP，优先级 high）
  - 说明：将风景背景、五类功能卡片、时长/会话控件组装为小憩主页面 RestModeView（面向驻车驾驶员单人场景的单屏布局），并接入联动：点击/操作卡片实时改变背景与氛围，背景随时段自动切换；将主页面挂载到 App 根组件。整体收口验收完整 UE。
  - 依赖：#1、#2、#3、#4、#5、#6、#7、#8
  - 验收标准：主页面在 1920×1080 下完整呈现风景背景+全部毛玻璃卡片+时长控件；所有卡片可点击操作；操作卡片能实时改变背景/氛围、背景随时段切换；npm run build 通过、页面无控制台报错。
