## 概述
面向新能源汽车驻车场景下驾驶员单人小憩，构建一套 1920×1080 定屏的可交互 UI（纯前端 UI/UE，不对接真实车控硬件，通过前端状态模拟车控反馈）。视觉采用毛玻璃卡片 + 大幅风景背景的放松风格，页面全部可点击、组件间联动。

## 技术选型
- 框架：Vue 3 + TypeScript + Vite（组件化、SFC 天然贴合卡片式布局）。
- 状态：Pinia 统一管理小憩会话状态与跨卡片联动（背景/氛围/时段切换）。
- 定屏适配：1920×1080 固定画布，采用 scale/transform 或 rem 基准做等比缩放，禁用滚动。
- 视觉：CSS backdrop-filter 实现毛玻璃；全屏风景背景层随时段/交互切换并做交叉淡入淡出过渡。

## 要点
- 视觉基础层（毛玻璃卡片 GlassCard、全屏背景 BackgroundScene、主题令牌）先行，被所有功能卡片复用。
- 五类功能卡片（座椅角度/按摩、氛围灯+背景音乐/白噪音、香氛、遮阳帘/车窗）相互独立、可并行开发，各自目录隔离。
- 小憩时长采用连续滑动自定义；小憩结束/唤醒以渐亮灯光 + 舒缓音乐提示，由会话编排模块统一驱动。
- 组件联动核心：点击卡片实时改变背景/氛围，风景随时段切换，由 Pinia store 集中调度、集成页组装。

## 影响范围
全新空仓库，从零搭建。按模块边界拆分：脚手架（前置）→ 视觉基础层 / 状态核心（并行）→ 五类功能卡片 + 会话编排（并行）→ 联动集成与主页面组装（收口）。各功能卡片 touched_files 目录互斥；主页面 App.vue 由脚手架创建、集成任务修改，用依赖串行化避免冲突。

## 非目标
- 不接入真实车辆总线/硬件；车控效果以前端状态与视觉/音效模拟。
- 不含多座位/行车中乘客场景、账户体系、后端服务。
