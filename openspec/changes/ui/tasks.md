# 任务清单

- [ ] #1 工程脚手架与 16:9 双栏布局壳（3 SP，优先级 high）
  - 说明：初始化 Vite + React 工程，配置依赖与入口，实现根容器 16:9 宽高比锁定与左窄右宽横向分栏布局壳（含左侧卡片区插槽、右侧地图区插槽的占位）。含常规静态资源（favicon、public/ 目录）。
  - 依赖：无
  - 验收标准：工程可 npm install 后 npm run dev 正常启动；页面根容器在 16:9 视口下呈现左右两栏，左栏为窄的竖向区域、右栏为宽的地图区域；两栏内先以占位块填充；含 favicon 等常规静态资源。

- [ ] #2 日夜双主题系统（跟随系统）（3 SP，优先级 high）
  - 说明：实现基于 CSS 变量的日/夜双主题：定义浅色与深色两套 token，提供 ThemeProvider/Context，默认读取系统 prefers-color-scheme 并随系统变化切换，全局组件通过变量取色。
  - 依赖：#1
  - 验收标准：存在浅色与深色两套 CSS 变量；应用启动时按系统 prefers-color-scheme 选定主题；模拟切换系统深浅色时页面配色随之切换；提供全局可用的主题上下文供组件消费。

- [ ] #3 左侧竖向信息卡片翻页容器（3 SP，优先级 high）
  - 说明：实现左栏竖向卡片堆容器：承载多张信息卡片，支持翻页/切换（点击与滑动两种手势），显示当前页/分页指示器，面向触控操作。卡片内容以子节点/插槽方式接入。切换过渡动画为可选增强项。
  - 依赖：#1
  - 验收标准：容器纵向填满左栏；可通过点击翻页，也可通过滑动手势翻页；有分页指示器标示当前卡片位置；触控点击可触发翻页；切换过渡动画为可选增强。

- [ ] #4 车辆状态卡片 + 时间/天气卡片（3 SP，优先级 normal）
  - 说明：实现两张信息卡片组件：车辆状态卡（车速、电量、续航）与时间/天气卡（当前时间、日期、天气），数据用本地 Mock，配色取自主题变量。
  - 依赖：#1
  - 验收标准：车辆状态卡展示车速、电量、续航三项数值；时间/天气卡展示当前时间、日期与天气信息；两卡使用主题变量取色，日夜主题下均清晰可读；数据来自本地 mock。

- [ ] #5 空调控制卡片 + 音乐媒体卡片（3 SP，优先级 normal）
  - 说明：实现两张信息卡片组件：空调与温度控制卡（温度显示与增减、风量等基本控件，前端状态自持）与音乐/媒体播放卡（曲目信息、播放/暂停/上下曲控件），数据与状态用本地 Mock。
  - 依赖：#1
  - 验收标准：空调卡展示当前温度并可通过控件调节（前端状态变化可见）；媒体卡展示曲目信息并提供播放/暂停、上一/下一曲控件且交互有前端反馈；均使用主题变量取色。

- [ ] #6 右侧地图占位面板（静态 Mock）（2 SP，优先级 normal）
  - 说明：实现右栏宽屏地图占位面板：展示静态占位图/Mock 地图（如静态图片或简易矢量占位），铺满右栏，预留后续接入真实地图 SDK 的容器与接口位，不接入真实地图服务。
  - 依赖：#1
  - 验收标准：右栏被地图占位面板铺满；显示静态占位地图内容（占位图或 mock 图形）；面板结构预留接入真实地图的容器；日夜主题下占位样式协调。

- [ ] #7 页面集成装配与联调（3 SP，优先级 high）
  - 说明：在 App 中装配全部组件：将四张卡片放入左侧翻页容器、地图面板放入右栏，接入主题 Provider，完成整页在 16:9 下的联调与视觉校准；并对日/夜双主题执行可量化的可读性校验（关键文本对比度阈值 + 日夜截图对比）。
  - 依赖：#1、#2、#3、#4、#5、#6
  - 验收标准：整页在 16:9 视口下：左栏翻页容器可在车辆状态/空调/媒体/时间天气四卡间切换，右栏显示地图占位；全局包裹主题 Provider，日夜切换整页生效；无控制台报错；日/夜两套主题下关键文本对比度均达到 WCAG AA（≥4.5:1），并留存日夜双主题整页截图对比作为可读性证据。
